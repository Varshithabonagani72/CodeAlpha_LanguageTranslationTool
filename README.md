# AI Powered Language Translation Tool

## Project Overview

- Developed as part of the Artificial Intelligence Internship at CodeAlpha
- AI based language translation application
- Translates text into multiple languages instantly
- Built using Python and Streamlit

## Features

- Multi language translation
- Text to speech voice output
- Translation history
- Real time translation
- Character counter
- Simple and interactive user interface

## Technologies Used

- Python
- Streamlit
- Googletrans
- gTTS (Google Text to Speech)

## Project Structure

CodeAlpha_LanguageTranslationTool/

app.py  
requirements.txt  
README.md  
screenshots/

## How to Run the Project

Step 1 Install Required Libraries

pip install -r requirements.txt

Step 2 Run the Application

streamlit run app.py

## Output

- User enters text
- Selects target language
- Application translates text instantly
- Voice output plays translated text
